# Simple-Coulomb-s-Law-Code
This was a beginner project to try turning math into code.


This code takes in values for q1 and q2, which are charges 1 and 2, and a distance r between them. Then, it returns both a value for the force in Newtons, and a graph showing the force drop-off over distance. The code for the force value was made by hand, but the code for the chart was copied from AI.
